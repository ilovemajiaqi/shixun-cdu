# 黄山旅游服务平台 (Huangshan Tourism Platform)

## 🛠 技术栈
- **Frontend**: Vue 3 + Tailwind CSS + Element Plus + Pinia + Echarts + Leaflet
- **Backend**: Java 17 (Spring Boot 3) + Spring Data JPA
- **DB**: MySQL 8.0
- **Cache**: Redis 7

## 🚀 快速启动 (Docker)
1. 确保 Docker Desktop 已运行。
2. 在根目录执行：`docker compose up --build`
   > *注意：首次构建可能需要几分钟下载依赖，请耐心等待。*
3. 访问前端：http://localhost:3001
4. 访问后端 API：http://localhost:8083

## 📸 功能介绍

### 🗺️ 用户端功能
- **景点导览**: 沉浸式浏览黄山核心景点（迎客松、光明顶等），支持列表与地图双模式查看。
- **路线规划**: 智能推荐“一日游精华线”、“二日游深度线”等经典游玩路线。
- **在线预订**: 支持景点门票和旅游路线的在线预订，模拟完整支付流程。
- **个人中心**:
  - **订单管理**: 实时查看订单状态，支持支付与取消操作。
  - **我的收藏**: 一键收藏心仪景点，方便快速访问。
  - **数据可视化**: 个人活跃度与消费统计图表。

### ⚙️ 管理端功能
- **数据仪表盘**: 基于 Echarts 的可视化大屏，实时监控订单量、收入趋势及用户活跃度。
- **资源管理**:
  - **景点管理**: 增删改查景点信息，支持图片上传与详情编辑。
  - **路线管理**: 灵活设计与发布新的旅游路线产品。
- **运营管理**:
  - **订单处理**: 审核用户订单，处理退款与确认操作。
  - **用户管理**: 查看注册用户列表，管控用户权限与状态。
